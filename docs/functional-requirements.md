# 機能要件:Trello風タスク管理アプリ

作成日:2026-10-12 / 作成者:futa / 版数:0.3 / 状態:たたき台(2026-10-25 列名変更、F-07 文字の色分け、F-10・UC-06 を追加。2026-11-02 並べ替えを、いつでもドラッグでできる形に変更し、移動先をドロップした位置に変更)
関連文書:[要件定義書](requirements.md)、[画面設計書](screen-design.md)、[データ設計書](data-design.md)

この文書は、「機能一覧」「機能詳細」「ユースケース」をまとめたもの。

## 1. 機能一覧(アプリができること)
| ID | 機能 | 内容 | 優先 |
|---|---|---|---|
| F-01 | 列の表示 | 未着手 / 作業中 / 完了 の3列を表示する | 必須 |
| F-02 | カード追加 | フォーム入力でカードを作り、未着手列の**一番上**に入れる(新しいカードが上に並ぶ) | 必須 |
| F-03 | カード表示 | タイトル・優先度・期限を表示し、説明文も確認できる | 必須 |
| F-04 | カード移動 | ドラッグして別の列へ移す | 必須 |
| F-05 | カード削除 | 不要なカードを消す。削除前に確認ダイアログ(「本当に削除しますか?」)を出す | 必須 |
| F-06 | データ保存 | 再読み込みしてもカードが残る | 必須 |
| F-07 | 優先度の色分け | 高=赤、中=黄、低=緑。カードの色と、カード上の【高】【中】【低】の文字の両方に付ける(2026-10-25 に文字の色分けを追加) | 必須 |
| F-08 | 期限切れ表示 | 期限の**翌日以降**になったカードを赤字にする(期限当日は赤字にしない) | 必須 |
| F-09 | カード編集 | 作成済みカードのタイトル・説明文・優先度・期限を後から修正できる | 必須 |
| F-10 | カードの並べ替え | 各列の「優先度順」「期限順」ボタンで、その列のカードを並べ替える。ボタンを押さなくても、いつでも、カードを同じ列の中でドラッグして好きな位置に並べ替えられる。並びはどちらも保存する(2026-10-25 追加、2026-11-02 変更) | 必須 |

## 2. 機能詳細
### 2.1 カードの項目
| 項目 | 必須 | 入力方法 | 上限 | 備考 |
|---|---|---|---|---|
| タイトル | 必須 | 1行入力 | 50文字 | 空では追加できない |
| 説明文 | 任意 | 複数行入力 | 500文字 | |
| 優先度 | 必須 | 高・中・低から選択 | - | 初期値は「中」 |
| 期限 | 任意 | 日付選択 | - | |

入力の上限は、データ設計書で正式に決定した値。

### 2.2 機能ごとの決まりごと
| 機能 | 決まりごと |
|---|---|
| F-02 カード追加 | 新しいカードは未着手列の一番上に入る |
| F-04 カード移動 | 移動したカードは、ドロップした位置に入る。列の余白に落とした場合は、その列の一番下に入る(2026-11-02 変更。変更前は「移動先の列の一番上」)。同じ列の中の並べ替えは F-10 で行う(2026-10-25 に、「同じ列内の並び替えはしない」から変更) |
| F-05 カード削除 | 削除前に必ず確認ダイアログを出す。削除したカードを元に戻す機能は作らない |
| F-07 優先度の色分け | カードの色と【高】【中】【低】の文字に、同じ色を使う(高=赤、中=黄、低=緑)。白い背景でも読めるよう、文字の黄は濃い黄土色にし、太字にする |
| F-08 期限切れ表示 | 期限が昨日以前なら赤字。期限が当日、または未設定なら赤字にしない |
| F-09 カード編集 | 編集してもカードは今の列、今の位置のまま動かない |
| F-10 カードの並べ替え(優先度順・期限順) | 列ごとのボタン。押した列のカードだけを並べ替え、その並びを保存する。優先度順は高→中→低、期限順は期限の近い順(期限なしは最後)。同じ優先度・同じ期限の中は、今の並びのままにする。ボタンを押したあとも、カードはドラッグで自由に並べ替えられる。元に戻すボタンは作らない |
| F-10 カードの並べ替え(自由な並べ替え) | ボタンを押さなくても、いつでも、カードを同じ列の中でドラッグして好きな位置に並べ替えられる(Trello と同じ)。ドロップした位置に入り、自分自身の上に落としても何も変わらない。並びは保存する。「並べ替えモード」ボタンは作らない(2026-11-02 変更。2026-10-25 の決定は、優先度順・期限順は表示だけで保存せず、自由な並べ替えは「並べ替えモード」ボタンを押している間だけ、だった) |

画面の操作方法は[画面設計書](screen-design.md)、データの動きは[データ設計書](data-design.md)を参照。

## 3. ユースケース
利用者がシステムを使ってやりたいこと(目的)を一覧にし、手順を記述する。
データの保存(F-06)は利用者が直接行う操作ではないため、独立したユースケースにせず、UC-02〜06 の事後条件に含める。

### 3.1 アクター
| アクター | 説明 |
|---|---|
| 利用者 | アプリを使う自分1人。ログインや担当者の区別はない |

### 3.2 ユースケース一覧
| ID | ユースケース | 対応する機能要件 |
|---|---|---|
| UC-01 | ボードを見る | F-01、F-03、F-07、F-08 |
| UC-02 | カードを追加する | F-02 |
| UC-03 | カードを編集する | F-09 |
| UC-04 | カードを移動する | F-04 |
| UC-05 | カードを削除する | F-05 |
| UC-06 | カードを並べ替える | F-10 |

(F-06 データ保存は、UC-01 の事前条件および UC-02〜06 の事後条件として扱う)

### 3.3 ユースケース記述
#### UC-01 ボードを見る
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 目的 | タスクの状況を一目で把握する |
| 事前条件 | ブラウザでアプリを開いている |
| 基本フロー | 1. システムが保存済みのデータを読み込む<br>2. 未着手 / 作業中 / 完了 の3列を表示する<br>3. 各カードのタイトル、優先度、期限を、属する列に表示する<br>4. 優先度を色で示す(高=赤、中=黄、低=緑。カードの色と【高】【中】【低】の文字の両方)<br>5. 期限の翌日以降のカードは、期限を赤字にする<br>6. 利用者がカードの説明文を確認する |
| 代替フロー | 1a. 保存データがない場合(初回など)は、カードのない3列を表示する<br>5a. 期限が当日、または未設定のカードは、赤字にしない |
| 例外フロー | なし(保存データの読み込み失敗は、非機能要件の検討で扱う) |
| 事後条件 | 最後に保存した状態のボードが表示されている |

#### UC-02 カードを追加する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 目的 | やることを新しいカードとして登録する |
| 事前条件 | ボードが表示されている |
| 基本フロー | 1. 利用者がカード追加の入力を始める<br>2. タイトルを入力する(必須)<br>3. 説明文、優先度(初期値「中」)、期限を必要に応じて入力する<br>4. 追加を確定する<br>5. システムが未着手列の一番上にカードを表示する<br>6. システムが内容を保存する |
| 代替フロー | 3a. 優先度を変えたい場合は、高・中・低から選ぶ |
| 例外フロー | 4a. タイトルが空の場合、システムは追加せず、入力を促すメッセージを表示する |
| 事後条件 | カードが未着手の先頭に追加され、再読み込みしても残っている |

#### UC-03 カードを編集する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 目的 | 作成済みのカードの内容を直す |
| 事前条件 | 編集したいカードがボードに表示されている |
| 基本フロー | 1. 利用者が編集したいカードを選び、編集を始める<br>2. システムが現在の内容(タイトル、説明文、優先度、期限)を入力欄に表示する<br>3. 利用者が内容を修正する<br>4. 修正を確定する<br>5. システムがカードの表示を更新する(カードは今の列、今の位置のまま)<br>6. システムが内容を保存する |
| 代替フロー | 3a. 期限を消して、期限なしに戻す<br>3b. 編集をやめる場合は、キャンセルする(内容は変わらない) |
| 例外フロー | 4a. タイトルを空にして確定した場合は、更新せず、入力を促すメッセージを表示する |
| 事後条件 | カードの修正が反映され、再読み込みしても残っている |

#### UC-04 カードを移動する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 目的 | タスクの進み具合に合わせて、カードの列を変える |
| 事前条件 | 移動したいカードがボードに表示されている |
| 基本フロー | 1. 利用者がカードをドラッグする<br>2. 別の列のカードの上、または列の余白でドロップする<br>3. システムがカードをドロップした位置(余白なら一番下)に移して表示する<br>4. システムが内容を保存する |
| 代替フロー | 2a. 元の列にドロップした場合は、同じ列の中の並べ替えになる(UC-06) |
| 例外フロー | 2b. 列の外でドロップした場合は、元の場所に戻る |
| 事後条件 | カードが移動先の列にあり、再読み込みしても残っている |

#### UC-05 カードを削除する
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 目的 | 不要になったカードを消す |
| 事前条件 | 削除したいカードがボードに表示されている |
| 基本フロー | 1. 利用者が削除したいカードを選び、削除を始める<br>2. システムが確認ダイアログ(「本当に削除しますか?」)を表示する<br>3. 利用者が削除を承諾する<br>4. システムがカードをボードから取り除く<br>5. システムが内容を保存する |
| 代替フロー | 3a. 利用者が取りやめた場合は、カードは削除されず、そのまま残る |
| 例外フロー | なし |
| 事後条件 | カードが消え、再読み込みしても戻らない |

#### UC-06 カードを並べ替える
| 項目 | 内容 |
|---|---|
| アクター | 利用者 |
| 目的 | 列の中のカードを、見たい順に並べて確認する・好きな順に整える |
| 事前条件 | ボードが表示されている |
| 基本フロー(ドラッグで自由に並べ替える) | 1. 利用者が同じ列の中でカードをドラッグする<br>2. 好きな位置(ほかのカードの前後、または列の余白)にドロップする<br>3. システムがカードをその位置に表示する<br>4. システムが並びを保存する |
| 基本フロー(優先度順・期限順) | 1. 利用者が列の「優先度順」または「期限順」ボタンを押す<br>2. システムがその列のカードだけを並べ替えて表示する(優先度順は高→中→低、期限順は期限の近い順で期限なしが最後。同じ優先度・同じ期限の中は、今の並びのまま)<br>3. システムが並びを保存する<br>4. 利用者は、並べ替えたあとも、ドラッグで自由に並べ替えられる |
| 代替フロー | 2a. 自分自身の上にドロップした場合は、何も変わらない |
| 例外フロー | 2b. 列の外でドロップした場合は、元の場所に戻る |
| 事後条件 | 並べ替えた並びが、再読み込みしても残っている |
