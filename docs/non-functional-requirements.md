# 非機能要件:Trello風タスク管理アプリ

作成日:2026-10-19 / 作成者:futa / 版数:0.1 / 状態:たたき台
関連文書:[要件定義書](requirements.md)、[技術スタック候補](tech-stack.md)

機能以外の条件をまとめた文書。利用者は1人という前提で、項目ごとに「数字にする」「簡単に扱う」「対象外」を判断した。

> **見直し待ち**:2026-10-20 に「実際のDBとバックエンドを作る」方針へ変えたため、下記のうち NF-04、NF-07、NF-10〜14 は、技術選定のあとに見直す(現在の記載は、ブラウザ内保存(localStorage)を前提にしている)。

## 1. 性能・拡張性
| ID | 項目 | 目標値 | 根拠 |
|---|---|---|---|
| NF-01 | 想定カード枚数 | 全体で200枚まで | 個人のタスクなら完了済みを含めても数十〜百数十枚。余裕を見て200 |
| NF-02 | 操作の反応時間 | カードの追加・編集・移動・削除が、200枚の状態でも1秒以内に画面へ反映される | 待たされたと感じない目安 |
| NF-03 | 起動時の表示時間 | アプリを開いてからボードが表示されるまで3秒以内 | 同上 |
| NF-04 | データ容量 | 200枚で約0.3MB以内(保存の上限は約5MB) | 1カード約1.2KB(タイトル50文字+説明文500文字、日本語は1文字最大2バイトで計算)×200枚=約240KB |

入力の上限(タイトル50文字、説明文500文字)は、NF-04 の計算に使う値で、データ設計書(data-design.md)で正式に決定した。

## 2. 環境
| ID | 項目 | 目標値 |
|---|---|---|
| NF-05 | ブラウザ | Chrome の最新版(Windows)。他のブラウザは対象外 |
| NF-06 | 画面サイズ | 幅1280px以上のパソコン画面。スマホ・タブレットは対象外 |
| NF-07 | 導入 | インストール不要。HTML ファイルをブラウザで開くだけで使える |
| NF-08 | 画面構成 | 画面は1ページだけ |

## 3. 使いやすさ
| ID | 項目 | 目標値 |
|---|---|---|
| NF-09 | 初めての操作 | 説明を見なくても、5分以内にカードの追加・移動・削除ができる(確認は作成者本人が行う) |

## 4. 信頼性(異常系)
| ID | 項目 | 内容 |
|---|---|---|
| NF-10 | 保存に失敗した場合 | 容量超過や保存不可のときは、エラーを画面に表示する。表示中の画面は壊さない |
| NF-11 | 保存データが壊れていた場合 | 空のボードで起動し、その旨を表示する |

## 5. 移行性・セキュリティ・運用保守(簡単に扱う)
| ID | 項目 | 内容 |
|---|---|---|
| NF-12 | データの保存先 | ブラウザの localStorage に保存する |
| NF-13 | データの引き継ぎ | バックアップや引き継ぎの機能は作らない。ブラウザのデータを消すとカードも消える(既知のリスク) |
| NF-14 | セキュリティ | ログインなし。データは端末内だけに保存し、外部へ送信しない。入力した文字は、そのままの文字として画面に表示する |
| NF-15 | 運用・保守 | 課題のため、運用や問い合わせ対応は行わない |

## 6. 対象外とする項目(理由)
| 項目 | 理由 |
|---|---|
| 可用性(止まらず使えること) | サーバーがなく、自分のパソコンで動くため |
| 多人数での同時利用 | 利用者は1人のため |
