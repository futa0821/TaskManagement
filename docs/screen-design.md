# 画面設計書:Trello風タスク管理アプリ

作成日:2026-10-20 / 作成者:futa / 版数:0.2 / 状態:たたき台(2026-10-25 列名変更、並べ替えボタン・優先度の文字色を追加)
関連文書:[要件定義書](requirements.md)

## 1. 画面設計の方針
- アプリは1ページだけで構成する(NF-08)。ページの上に重なる入力ウィンドウや確認ダイアログも、別の「画面」として数える。
- 画面の幅は1280px以上のパソコン画面を前提とする(NF-06)。
- 説明文の確認、追加、編集、削除の操作は、次の「3. 決定事項」に従う。

## 2. 画面一覧
| ID | 画面 | 役割 | 関係するユースケース |
|---|---|---|---|
| S-01 | ボード画面 | 3列とカードを表示する。すべての操作の起点 | UC-01、UC-04、UC-06 |
| S-02 | カード入力モーダル | 追加と編集で共用する入力ウィンドウ。説明文の確認も兼ねる | UC-02、UC-03 |
| S-03 | 削除確認ダイアログ | 削除してよいかを確認する | UC-05 |

## 3. 決定事項
- 説明文はカード上に表示せず、カードをクリックして開く S-02 で確認する(確認と編集を兼ねる)(2026-10-20 決定)
- カードの追加は、未着手列の上の「+ カードを追加」ボタンから、S-02 を開いて行う(2026-10-20 決定。2026-10-25 に列名を To Do から未着手へ変更)
- カードの編集は「カードをクリック」、削除は「カードの🗑ボタン」で行う(2026-10-20 決定)
- 並べ替えは、各列の見出しの下のボタンで行う。「優先度順」「期限順」は押した列だけを一時的に並べ替え(保存しない)、「並べ替えモード」は同じ列の中でドラッグして並べ替える(保存する)(2026-10-25 決定)
- 「優先度順」「期限順」を元に戻す専用ボタンは作らず、選択中のボタンをもう一度押して解除する(2026-10-25 決定)
- 優先度の色は、カードの色に加えて、【高】【中】【低】の文字にも付ける(2026-10-25 決定)
- 画面の文字は游ゴシックにし、背景色は薄めのグレーにする(2026-10-25 決定)
- 画面上部のタイトルは「Task Management」(游ゴシック、白字)とし、背景はボードの中で一番濃いグレーにする。列(未着手・作業中・完了)の背景は、落ち着いた青系のスチールブルー(#c5d3e6)にして、ボードの背景と見分けやすくする(2026-10-25 決定。当初はグレーにしたが、ボードの背景と区別しにくいため、青系に変更した)

## 4. 画面レイアウト(ワイヤーフレーム)
### 4.1 S-01 ボード画面
```
┌─────────────────────────────────────────────────────────────┐
│  Task Management                                             │
├───────────────────┬───────────────────┬─────────────────────┤
│ 未着手 (3)        │ 作業中 (1)        │ 完了 (2)            │
│ [優先度順][期限順] │ [優先度順][期限順] │ [優先度順][期限順]   │
│ [並べ替えモード]   │ [並べ替えモード]   │ [並べ替えモード]     │
│ [+ カードを追加]   │                   │                     │
│ ┌───────────────┐ │ ┌───────────────┐ │ ┌─────────────────┐ │
│ │■【高】資料を作る│ │ │■【中】レビュー │ │ │■【低】掃除       │ │
│ │ 期限 10/20 [🗑]│ │ │ 期限 10/25 [🗑]│ │ │ 期限 なし   [🗑] │ │
│ └───────────────┘ │ └───────────────┘ │ └─────────────────┘ │
│ ┌───────────────┐ │                   │                     │
│ │■【中】…        │ │                   │                     │
│ └───────────────┘ │                   │                     │
└───────────────────┴───────────────────┴─────────────────────┘
  ■ = 優先度の色(高=赤、中=黄、低=緑)。【高】【中】【低】の文字も同じ色にする
  期限が昨日以前のカードは、期限の文字を赤にする
  各列の3つのボタン(優先度順・期限順・並べ替えモード)は、図では2行に分けたが、実際の画面では1行に並べる
  選択中の「優先度順」「期限順」ボタンは色を変えて示す
  並べ替えモード中は、その列のボタンの表示が「並べ替え完了」に変わり、優先度順・期限順ボタンは押せなくなる
```

## 6. 画面項目定義
### 6.1 S-01 ボード画面
| 項目 | 内容 | 備考 |
|---|---|---|
| 列見出し | 列名(未着手 / 作業中 / 完了)とカード枚数 | F-01 |
| 優先度順ボタン | 各列の見出しの下。押すとその列だけ、高→中→低の順に並べ替える | F-10。表示だけで保存しない。選択中は色を変え、もう一度押すと解除して保存済みの並びに戻る |
| 期限順ボタン | 各列の見出しの下。押すとその列だけ、期限の近い順に並べ替える(期限なしは最後) | F-10。優先度順ボタンと同じ扱い。同時に選べるのは、どちらか一方 |
| 並べ替えモードボタン | 各列の見出しの下。押すとその列が並べ替えモードになり、表示が「並べ替え完了」に変わる | F-10。モード中は、その列の優先度順・期限順ボタンと、別の列へのドラッグ移動が使えない。「並べ替え完了」で並びを保存する |
| カード追加ボタン | 「+ カードを追加」。未着手列の上だけに置く | 押すと S-02(追加)を開く。F-02 |
| カード | 優先度の色、優先度の文字(【高】【中】【低】)、タイトル、期限、🗑ボタン | F-03。説明文は表示しない |
| 優先度の色 | 高=赤、中=黄、低=緑。カードの色と、【高】【中】【低】の文字に使う | F-07。文字の黄は、白い背景で読めるよう濃い黄土色にし、太字にする |
| 期限の表示 | M/D の形式。期限なしは「なし」 | 内部では年を含めて保持する |
| 期限切れの表示 | 期限の翌日以降は、期限の文字を赤にする。当日は赤にしない | F-08 |
| 🗑ボタン | 押すと S-03 を開く | カードをクリックしても S-02 は開かない |
| カードのクリック | S-02(編集)を開く | F-09、説明文の確認 |
| ドラッグ(通常時) | 別の列へドロップすると移動する | F-04。移動先の列の一番上に入る。同じ列の中でドロップしても何も変わらない |
| ドラッグ(並べ替えモード中) | その列の中でドロップすると、ドロップした位置に並ぶ | F-10。列の外でドロップすると元の場所に戻る。変更前(2026-10-25 より前)は、同じ列内の並び替えはしない決まりだった |

### 6.2 S-02 カード入力モーダル
| 項目 | 型 | 必須 | 上限 | 備考 |
|---|---|---|---|---|
| タイトル | 1行入力 | 必須 | 50文字 | 空のままでは保存できない |
| 説明文 | 複数行入力 | 任意 | 500文字 | 編集時はここで全文を確認できる |
| 優先度 | 選択(高・中・低) | 必須 | - | 追加時の初期値は「中」 |
| 期限 | 日付選択 | 任意 | - | 消して「期限なし」に戻せる |
| キャンセルボタン | ボタン | - | - | 入力内容を捨てて S-01 に戻る |
| 保存ボタン | ボタン | - | - | 入力内容を確定して S-01 に戻る |

- 追加時は、各項目が初期値の状態で開く。編集時は、カードの現在の内容が入った状態で開く。
- タイトルが空のまま保存を押した場合は、保存せず、M-01 を表示して S-02 を開いたままにする。
- 文字数の上限は、データ設計書(data-design.md)で正式に決定した値。

### 6.3 S-03 削除確認ダイアログ
| 項目 | 内容 |
|---|---|
| メッセージ | M-02 |
| 「削除する」ボタン | カードを削除して S-01 に戻る |
| 「やめる」ボタン | 何も変えずに S-01 に戻る |

## 7. メッセージ定義
| ID | 表示する場面 | 文言 | 備考 |
|---|---|---|---|
| M-01 | タイトルが空のまま保存 | タイトルを入力してください | |
| M-02 | 削除の確認 | 本当に削除しますか? | |
| M-03 | 保存に失敗 | 保存できませんでした。もう一度お試しください | 暫定。保存の仕組みが決まったら見直す |
| M-04 | データの読み込みに失敗 | データを読み込めませんでした | 暫定。保存の仕組みが決まったら見直す |

## 8. 操作と機能・ユースケースの対応
| 利用者の操作 | 画面 | ユースケース | 機能要件 |
|---|---|---|---|
| アプリを開く | S-01 | UC-01 | F-01、F-03、F-07、F-08 |
| 「+ カードを追加」を押し、入力して保存 | S-01 → S-02 | UC-02 | F-02 |
| カードをクリックし、修正して保存 | S-01 → S-02 | UC-03 | F-09 |
| カードをドラッグして別の列へ | S-01 | UC-04 | F-04 |
| 列の「優先度順」「期限順」を押す | S-01 | UC-06 | F-10 |
| 列の「並べ替えモード」を押し、ドラッグして並べ替え、「並べ替え完了」を押す | S-01 | UC-06 | F-10 |
| 🗑を押し、削除を承諾 | S-01 → S-03 | UC-05 | F-05 |
| 再読み込みしても内容が残る | S-01 | UC-01(事前条件) | F-06 |
