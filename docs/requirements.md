# 要件定義書:Trello風タスク管理アプリ

作成日:2026-10-12 / 作成者:futa / 状態:たたき台(確認待ち)

## 1. 目的・背景
- AIエンジニアコースの課題として、Trello風のタスク管理アプリを作る。
- Trello のような**カンバンボード形式**で、タスクの状態(未着手・作業中・完了)を視覚的に管理できるようにする。
- やることをカードにして、列の間を動かし、進み具合を一目で分かるようにする。

## 2. 利用者・利用環境
- 利用者:自分1人(ログインや担当者の管理は不要)
- 環境:パソコンのブラウザ(Chrome など)のみ
- サーバーやデータベースは使わない(データはブラウザ内に保存する)

## 3. 用語
| 用語 | 意味 |
|---|---|
| ボード | 画面全体 |
| リスト(列) | To Do / Doing / Done の縦の列 |
| カード | 1つのタスク |

## 4. 機能要件(アプリができること)
| ID | 機能 | 内容 | 優先 |
|---|---|---|---|
| F-01 | 列の表示 | To Do / Doing / Done の3列を表示する | 必須 |
| F-02 | カード追加 | フォーム入力でカードを作り、To Do 列に入れる | 必須 |
| F-03 | カード表示 | タイトル・優先度・期限を表示し、説明文も確認できる | 必須 |
| F-04 | カード移動 | ドラッグして別の列へ移す | 必須 |
| F-05 | カード削除 | 不要なカードを消す。削除前に確認ダイアログ(「本当に削除しますか?」)を出す | 必須 |
| F-06 | データ保存 | 再読み込みしてもカードが残る | 必須 |
| F-07 | 優先度の色分け | 高=赤、中=黄、低=緑 | 必須 |
| F-08 | 期限切れ表示 | 期限を過ぎたカードを赤字にする | 必須 |

### カードの項目
| 項目 | 必須 | 入力方法 | 備考 |
|---|---|---|---|
| タイトル | 必須 | 1行入力 | 空では追加できない |
| 説明文 | 任意 | 複数行入力 | |
| 優先度 | 必須 | 高・中・低から選択 | 初期値は「中」 |
| 期限 | 任意 | 日付選択 | |

## 5. 非機能要件(機能以外の条件)
- 動作:最新の Chrome で動く。
- 導入:インストール不要。index.html を開くだけで使える。
- 保存:ブラウザの localStorage に保存する(ブラウザのデータを消すと消える)。
- 使いやすさ:画面は1ページだけで、操作は迷わない簡単なものにする。

## 6. 対象外(今回は作らない)
列の追加・名前変更、カードの編集、担当者、ラベル、検索、複数人での共有。
これらの機能追加は、基本機能が完成した後に改めて検討する。
